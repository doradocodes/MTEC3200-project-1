# Problem Statement

When I plan the time before teaching, whether that's noticing when to stop working or timing my commute, I have to guess how much buffer I need, which is frustrating because I consistently underestimate it and arrive rushed. I think this happens because I don't build in a cushion for the unpredictable part of that transition. What I wish happened instead is having a consistent buffer that absorbs the surprise, whatever it turns out to be that day.
